# 孪晶与空间群判据

## 先看独立证据

- 非相干晶畴叠加强度。在公共校正强度基准上，双畴模型为 I(h)=s[(1−α)|F(h)|²+α|F(Th)|²]。T 作用于倒易列向量，基变换 h′=Ch 对应 T′=CTC⁻¹。独立峰与混合峰保留共同来源和各自贡献者。
- Merohedry 所对应的晶格多余点群操作是候选孪晶律。真正缺失的镜面、滑移面和反心是结构对称假设。倒易层未覆盖时记录应测、实际覆盖和有效观察的数量。
- 理想未孪晶的 ⟨|E²−1|⟩，中心反射约 0.968，非中心反射约 0.736。以分辨率归一化，并同时检查赝平移、各向异性、覆盖和尺度误差。L 统计、律相关对和 Fo/Fc 残差均用于提出候选。
- 半晶胞 Patterson 候选同时查看奇偶类的实测数、归一强度和覆盖掩膜。如果一类未测，记录其覆盖缺口。其他平移向量可在工作数据的 Patterson 图上继续检查。
- 低对称单畴、低对称孪晶和候选高对称结构在同一观测上比较。ADDSYM 的坐标吻合、消光、跨批次强度和压低差值密度分别记录。孪晶能把另一畴的允许反射带入本畴禁反射的位置。
- 反演孪晶使用独立的 I(h)、I(−h) 及异常散射证据。占比约 0.5 可对应真实的等比例反演孪晶。结合可用异常信号、参数区间和竞争结构判断。Friedel 已合并时报告绝对结构的观测限制。

## 按重叠类型选精修

- 精确重叠且原始强度与模型基底一一可核对时，HKLF 4 可进行 `TWIN` 与 `BASF` 精修。SHELXL 的负矩阵元素是矩阵元素本身，−I 表示反演。`TWIN` 末尾的负分量数按手册描述联合反演分量。
- 赝度量、网格孪晶、分裂峰及部分重叠以探测器和扫描轴的真实峰宽分类。使用全预测检查贡献者，选有判别力的已有帧复查，再根据结果扩大积分。仅有合并 HKL 时，剩余独立峰及部分重叠所需证据来自未合并观测或原始帧。
- HKLF 5 保留每个真实观测组。前面各贡献者的分量编号为负，末条为正。组总强度在似然中只使用一次，协方差用主记录保存。模型条件的去孪晶输出从适用 SHELXL 版本的 `LIST 8` FCF 获得，记录其来源，原始观测作为证据。
- `SWAT` 是弥散溶剂的结构因子模型。尺度和吸收依据实验校正。占比的边界及近共线情形以区间、有效秩和独立观测评估。

## 交叉检查

- ADDSYM 使用安装的 `platon -m MODEL.cif` 或配对 RES，保存在单独临时目录。候选的原点和基变换须验证在所用强度上成立。
- TwinRotMat 使用 `platon -T1 MODEL.fcf`，捕获 stdout 中的判断部分并设时间预算。优先原始测量与计算强度对应的 FCF。特定 SHELXL/PLATON 版本需要权重元数据时，`scripts/fix_fcf_for_twinrotmat.py` 从同一次精修的 ACTA CIF 或 INS 补齐副本。已经完整的 FCF 可直接使用。模型条件的去孪晶 FCF 单独标明。
- 把观测角色冻结在候选生成前。相关强度、Friedel 对、孪晶伴随指数和共享像素放入同一角色。保留模型选择与最终审计两个阶段。
